## 600 Gbps 防护是加购项，不是默认配置

官网首页写着“up to 600 Gbps mitigation capacity”，很容易被读成默认自带。官方文档把这件事讲清楚了：所有实例默认只有尽力而为的基础清洗，600 Gbps 高级清洗是付费加购。

基础防护的实际边界是这样的：系统自动检测异常流量并做基础清洗，无需配置。但当某台实例遭到大规模攻击、影响到同网段其他客户时，系统会对该 IP 执行黑洞，持续 30 到 60 分钟，自动解除，无法人工干预。黑洞期间进出流量全部丢弃，服务直接不可用。

对普通建站用户，这套机制够用。对游戏服、金融类业务或者任何“断半小时就是事故”的场景，要么提前买高级清洗，要么在架构上做准备。别等到被打进黑洞了才去看文档。
